# climbing_progression_tracker
--- 
Allows you (the climber) to track, view, and store sends that you have done!
Analytics coming soon! 

## **Initial Setup**
---
1. git clone this repository
2. cd into the folder you clone this repository into


## **Installation instructions for Frontend**
---

1. cd into the 'frontend' folder
2. Run 'npm install' (make sure you are in the root directory!)


## **Installation instructions for Backend**
---

1. Install python on your machine
2. cd into the 'backend' folder
3. Create a virtual enviroment (this is created as to not interfere with any other projects that utilize python)
4. Activate the virtual environment (on Windows venv\Scripts\activate : on Mac/Linux source .venv/bin/activate)
5. Run 'install -r requirements.txt'

## **Starting the Frontend**
---
1. open a command prompt
2. cd into frontend folder
3. npm start
4. make sure that the local host address is http://localhost:5173/

## **Starting the Backend**
---
1. open a command prompt
2. cd into the backend folder
3. Activate the virtual environment
4. Run 'python run.py'

Your Climbing Progression Tracker should now be running! Go send some cool climbs and track your progression!
